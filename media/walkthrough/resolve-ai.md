# Resolve with AI

**Resolvr: Resolve with AI** hands your open threads to a coding agent in the integrated terminal. Resolvr generates `.review/AGENTS.md` with the session context, so the agent knows every thread, anchor, and message — it fixes the code and replies in-thread.

Pick your agent in settings:

- `resolvr.codingAgent`: `claude` (default), `codex`, or `gemini`

The agent CLI must be installed and on your `PATH`. When it finishes, resolved threads update live in the sidebar — the session file is the handshake.

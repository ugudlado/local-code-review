# Start a review thread

Open any changed file and hover over the gutter — click the **＋** to comment on that line, exactly like a PR review.

Threads live in `.review/sessions/<branch>-code.json` in your repo (gitignored). That one file is the whole review: the sidebar _Threads_ view, inline comments, browser annotations, and AI agents all read and write it.

From each thread you can **Reply**, **Resolve**, **Won't Fix**, or **Mark Outdated** — inline or from the Threads view.

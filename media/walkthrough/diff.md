# The diff view

**Resolvr: Open Diff** populates the _Changed Files_ tree in the Explorer sidebar — every file changed against the target branch, expandable to individual hunks.

- Click a file to open a side-by-side diff against the base revision
- Click a hunk to jump straight to it
- Use **Resolvr: Next Hunk** / **Previous Hunk** to step through the whole review as one stream
- Toggle tree/flat layout with the list icon in the view title

Badges show each file's status (added, modified, deleted) and how many review threads it carries.
